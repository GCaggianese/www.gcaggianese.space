## A clear result, not a configuration maze

I troubleshoot Linux servers and Docker deployments, then leave you a verified result, clear findings and practical handover notes. We agree on one outcome and how we will know it worked before I start changing the system.

## What I can help with

- **Linux and VPS troubleshooting:** investigate service failures, networking problems and deployment issues.
- **Docker and Docker Compose:** diagnose containers, internal networking, persistence and application startup.
- **Nginx, DNS and HTTPS:** trace reverse-proxy routing, hostname configuration and SSL/TLS failures.
- **Server migration and recovery:** plan or execute a bounded move, backup or restore task with explicit verification.

## Start with a bounded diagnostic

For an unclear failure, we can start with a **30-minute paid diagnostic through Upwork**. We review the stack, symptoms, recent changes and sanitized logs or configuration. You receive a concise written summary within one day, including findings, recommendations and anything that still requires verification.

The consultation is for diagnosis and next steps, not a guaranteed repair. If implementation makes sense, we agree on a separate scope.
